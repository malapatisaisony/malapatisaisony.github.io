Full-stack engineering

Scalable Job Application Tracker

A full-stack application for managing job applications, with secure access and an emphasis on backend engineering.

What I built

  • JWT access and refresh authentication, refresh-token revocation, user-level authorization, search, filtering, and pagination.
  • PostgreSQL composite indexes, Redis caching, and Redis-backed per-user rate limiting.
  • Flyway migrations, Swagger/OpenAPI documentation, Actuator/Prometheus metrics, and request correlation logging.
  • Automated tests, Docker Compose, and GitHub Actions full-stack CI.
  • Java
  • Spring Boot
  • React
  • PostgreSQL
  • Redis

Data + AI engineering

FloatChat

An AI-powered ocean data analytics platform that connects a conversational interface to ARGO oceanographic datasets.

What I built

  • A React/TypeScript frontend and FastAPI backend for querying and exploring ocean measurements.
  • Data-ingestion workflows using pandas and xarray to process NetCDF data, with SQLAlchemy and Pydantic for persistence and validation.
  • A retrieval-augmented generation pipeline using ChromaDB and Gemini for semantic retrieval and natural-language-to-SQL query generation.
  • Python
  • FastAPI
  • TypeScript
  • PostgreSQL
  • ChromaDB
  • Gemini
